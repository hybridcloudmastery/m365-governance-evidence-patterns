# Security and Responsible Disclosure

This is a documentation-only repository. It contains no production automation, credentials, tenant configuration or customer evidence.

## Do not submit live tenant data

Do not include personal, customer or tenant information in public issues, pull requests or screenshots. This includes:

- names, email addresses and identifiers;
- tenant identifiers and internal URLs;
- IP addresses;
- prompts, responses or conversation identifiers;
- raw audit exports;
- credentials, tokens, secrets or certificates.

Use fictional or fully sanitized information when discussing an evidence pattern.

## Reporting a concern

Report security, privacy or material accuracy concerns privately through the contact details on [HybridCloudMastery.eu](https://hybridcloudmastery.eu/).

Include the affected document, the potential consequence, a sanitized explanation and an authoritative source supporting the correction.

## Evidence handling

Organizations applying these concepts should use authorized access, minimize retained personal data, restrict collected evidence, define a retention period and redact sensitive information before external disclosure.

This repository does not provide incident response or support for individual Microsoft 365 tenants.
